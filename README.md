## Cài đặt

Để cài đặt dự án, bạn cần thực hiện các bước sau:

1. Run project:

    ```bash
    php artisan serve

    ```

2. Truy cập vào đường dẫn để xem ứng dụng:
    ```bash
    http://127.0.0.1:8000
    ```

Đóng góp
Nếu bạn muốn đóng góp cho dự án, vui lòng tạo pull request và tuân thủ các quy tắc đóng góp.
